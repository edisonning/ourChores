# 甜甜家务微信小程序

独立 uni-app / Vue 3 / Pinia 工程。与网页共用 `server` 和现有数据库；支持登录、今日、任务、心愿、天平五页。无微信身份绑定，无需 AppSecret。

## 启动与导入

需要 Node.js 22.13+、Corepack 和微信开发者工具。从仓库根目录运行：

```sh
corepack pnpm install
corepack pnpm --filter server start
# 另一个终端
corepack pnpm dev:mp-weixin
```

在微信开发者工具导入 `miniapp/dist/dev/mp-weixin`，点击“编译”。四个标签页使用原生导航栏和 tabBar。开发构建持续监听源码变化。

```sh
corepack pnpm build:mp-weixin
# 生产构建导入 miniapp/dist/build/mp-weixin
corepack pnpm build
corepack pnpm test
```

## 配置

根目录 `.env` 设置 `WECHAT_APPID` 与 `VITE_API_BASE_URL`，参照 `.env.example`。也识别 `AppID: ...`、`小程序appid: ...`（含中文冒号）。没有 AppID 时使用游客模式，预览和真机能力需要有效 AppID。修改配置后重启构建。

`VITE_API_BASE_URL` 必须包含 `/api`，例如 `http://192.168.3.19:3000/api`。环境变量可覆盖文件，未配置时默认 `http://127.0.0.1:3000/api`，仅适合模拟器。

构建脚本只提取 AppID 与接口地址；AppSecret 不读取、不注入。`src/manifest.json` 是每次启动生成的本地文件，已忽略。PNG 是已有 Logo 与一致线条图标的本地资源，重新生成可运行 `node miniapp/scripts/assets.mjs`。

## 手机连接本地后端

1. 手机与电脑连接同一 Wi-Fi。启动服务时终端会显示电脑地址，选择 Wi-Fi 局域网地址（忽略 VPN/TUN 地址）。
2. 将接口配置为该地址加 `/api`，重新构建。手机不能使用 localhost / 127.0.0.1。
3. 开发者工具“详情 → 本地设置”中，开发调试启用“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。本地工程配置 `urlCheck: false`；真机如提示域名问题，在手机调试菜单开启调试后重试。
4. 点击“预览”或“真机调试”，用户用有项目权限的微信扫码。用两个成员身份完成下面的验收流程。

连接失败时：先在手机浏览器访问 `http://电脑IP:3000/api/users`，应看到成员列表；检查服务是否启动、防火墙是否允许 Node、Wi-Fi 是否隔离设备、VPN 是否改变路由，以及接口地址是否带 `/api`。此处只面向本地调试，未配置线上合法 HTTPS 域名和发布流程。

## 用户路径与状态

- 选成员 → 四位 PIN → 今日；本地存储记住登录。切换身份清空四页数据和未提交表单，旧请求响应被忽略。
- 今日支持打卡、确认、打回、重做、逾期状态。可见时每 30 秒刷新，隐藏停止；所有标签页显示时、下拉时刷新。
- 任务支持每天／每周多选／单次日期、成员分配、新增、编辑和删除。小程序编辑用 PUT，网页 PATCH 保留同一服务端处理器。
- 心愿支持新增、删除、兑换扣糖果、对方兑现和最近 50 条兑换记录。
- 统计使用后端周／月口径；完成率和糖果只计算已确认任务。
- 操作期间禁用重复提交；写入请求不自动重试。断网保留输入，点击“刷新重试”核对结果后再决定是否重新提交（网络超时不代表服务端一定没执行）。PIN 错误就地显示；其他 401 清会话并返回登录。

## 验证

`corepack pnpm test` 使用临时独立数据库启动测试服务，不接触 `server/data.db`。覆盖 PUT/PATCH 行为一致、双向打卡确认、自确认拦截、打回重做、扣糖果、余额不足、自行兑现拦截、统计、删除后历史保留，以及客户端会话和网络行为。

真机待用户完成：新建任务 → 本人打卡 → 切换对方确认 → 本人兑换 → 对方兑现。模拟器检查不替代真机验收。详见 `../docs/微信小程序验收记录.md`。
